# CARVE RUSH 2.2 — 3D 알파인 스키 (WebGL)

`https://1usenoah.github.io/carve-ski-game/` 에서 바로 플레이할 수 있는 **Three.js 기반 3D 스키 레이싱 게임**입니다.
2.0 의 세계·물리 위에 **조작감, 크라우칭 자세, 모드별 점프 분리**를 얹고, 2.2 에서 **게이트를 실제 FIS
자이언트슬라롬 / 슈퍼-G 규격으로 전면 재설계**했습니다 — 게이트 구조·코스 세팅·통과 판정·블루 다이 라인·폴 힌지까지
월드컵 중계 화면과 FIS 경기규정(ICR)에 맞췄습니다.

## 플레이 방법 (v2.2)

| 입력 | 동작 |
| --- | --- |
| `←` `→` (A / D) | 카빙 — 입력 즉시 에지가 물고, 호는 그대로 살아 있습니다 (steer 9.6 / edge 9.0 댐핑) |
| `↑` (W) / `Shift` | 턱 — 알파인 다운힐 에어로 크라우칭 |
| `↓` (S) | 브레이크 |
| `Space` | 점프 — **PARK 모드 전용**. RACE 에서는 입력 자체를 무시합니다 |
| `Enter` | 메뉴에서 선택한 런 시작 |
| `P` / `O` | 상점 · `Esc` 일시정지 · `M` 음소거 |

**모바일**은 화면을 **좌우로 드래그**하면 그 비례만큼 부드럽게 카빙하고(화면 좌/우 절반을 눌러도 조향),
아래로 스와이프하면 브레이크입니다. 하단 UI 는 `BRAKE` · `CROUCH` 두 개의 홀드 버튼만 남았고,
`AIR` 버튼은 RACE 모드에서 `display:none` 으로 완전히 사라집니다(PARK 에서만 등장).

### 모드

* **RACE** — FIS GS 세팅 **28개 게이트**(약 1 km, 34~41 m 간격) 슈퍼-G 코스, 실시간 타이머,
  Gold/Silver/Bronze(**Course Setter** 패널에 목표 기록 표시), 최고 기록과 **고스트 리플레이**.
  게이트는 **게이트 라인**(안쪽 터닝 폴 ↔ 바깥 폴)을 통과해야 인정되며, 터닝 폴에 붙을수록 좋은 판정입니다
  (`APEX PERFECT` / `CLEAN LINE` / `TIGHT CARVE` / `WIDE LINE`). 폴 안쪽으로 파고들거나 게이트 라인을 벗어나면
  `MISSED GATE` **+2.00초**. **점프 없음.**
* **PARK** — 게이트 없이 킥커 3개와 레일 2개에서 에어타임·스핀·그라인드를 쌓는 프리 라이드. 점프는 여기서만.

## v2.2 에서 바뀐 것 — 게이트를 FIS 월드컵 규격으로

### 1. 게이트 하나 = 깃발 2쌍 (폴 4개 + 패널 2장)

FIS ICR 은 다운힐·슈퍼-G·자이언트슬라롬의 게이트를 **폴 4개와 패널 2장**으로 정의합니다(ICR 901.2.1 / 1001.3.1).
이전 버전은 폴 2개짜리 "패널 게이트" 하나였지만, 이제 게이트는 이렇게 서 있습니다.

| 요소 | 규격 (반영값) |
| --- | --- |
| 패널 | **0.75 × 0.50 m** (ICR: 약 75 × 50 cm), 아래단이 설면에서 **1.0 m** 위 |
| 깃발 1쌍 | 폴 2개 (간격 0.70 m, 높이 2.02 m) + 그 사이에 매달린 패널 1장 |
| 게이트 1개 | **터닝 게이트**(안쪽, 폴 2 + 패널 1) + **아웃사이드 게이트**(바깥, 폴 2 + 패널 1) |
| 게이트 폭 | 터닝 폴 ↔ 아웃사이드 폴 **5.6 ~ 7.3 m** (ICR GS 4~8 m) |
| 색 | 한 게이트의 두 패널은 **같은 색**, 게이트마다 **빨강 → 파랑 교대** (ICR 901.2.2) |
| 방향 | 패널은 진입 방향을 정면으로 마주보되, 다음 게이트와의 사선 각도만큼 틀어 세팅 (실제 코스 세터처럼) |

### 2. 코스 세팅 — 롱/미디엄/숏 턴 + 딜레이드 게이트

`layout()` 이 16가지 문장(PHRASE)을 반복해 **긴 턴·중간 턴·짧은 턴**을 섞고, 문장 중간에 **딜레이드 게이트**
(같은 쪽으로 게이트를 두 번 세워 리듬을 늦추는 구간)를 넣습니다. 게이트 간격은 34~41 m, 터닝 폴끼리의
가로 간격은 16~22 m 로 FIS 최소 기준(연속 터닝 폴 10 m 이상)을 넉넉히 넘습니다.

### 3. 통과 판정 — 게이트 라인

각 게이트는 **터닝 폴에서 아웃사이드 폴로 이어지는 게이트 라인**을 가집니다. 스키어의 이번 프레임 이동이
그 게이트의 평면을 가로지른 순간, 교차점이 라인 위 어디인지로 판정합니다.

* 라인 **안쪽(터닝 폴 패널 구간)을 통과** → 통과. 터닝 폴에 가까울수록 `APEX PERFECT`,
  이어서 `CLEAN LINE` / `TIGHT CARVE` / `WIDE LINE`.
* **터닝 폴 안쪽(코스 중앙 쪽)으로 파고들면** → `MISSED GATE · CUT INSIDE THE TURNING POLE` **+2.00 초**.
* **아웃사이드 폴 바깥으로 벗어나면** → `MISSED GATE · OUTSIDE THE GATE LINE` **+2.00 초**.

### 4. 블루 다이 라인 (Blue Dye Line)

월드컵 중계에서 보이는 파란 염료 라인을 눈 위에 그립니다. 스프레이 질감(가장자리 노이즈)을 가진 염료
텍스처를 리본으로 깔아, ①게이트마다 **게이트 라인 가로선**, ②터닝 폴 바로 바깥을 감아 도는 **S자 카빙 레이싱
라인**(헤르마이트 곡선, 각 게이트 터닝 폴에서 0.85 m 바깥), ③코스 양쪽 **사이드 가이드 라인**을 표시합니다.
터닝 폴에는 **다음 게이트 방향 셰브런**과 발광 링을 두어 어느 폴을 끼고 돌아야 하는지(좌턴/우턴)를 즉시 알 수 있습니다.

### 5. 게이트 힌지 (Cross-blocking)

스키어가 패널을 스치면 **깃발 세트 전체가 눈 바닥 힌지를 축으로 휙 넘어갔다가**(피크 ≈ 0.6~1.1 rad)
2.4 Hz 스프링으로 좌우로 흔들리며 제자리로 돌아옵니다. 눈 가루가 튀고 타격음이 함께 납니다.
폴 하나가 아니라 **패널 한 장(깃발 1쌍) 단위**로 꺾이는 것이 실제 게이트와 같습니다.

### 6. 물리 · HUD

* 최대 에지 64° → **68°**, 선회 상한 1.7 → **1.85 rad/s**: 22 m 폭 S자 GS 아치를 월드컵 속도로 카빙할 수 있게.
* 게이트 카운터 **28**, 목표 기록 Gold 66 / Silver 74 / Bronze 84 초로 재산정.

**규격 출처**
* FIS ICR Book IV (Alpine), edition July 2025 — 680 Poles / 690 Gate Panels / 901 Giant Slalom / 1001 Super-G
  <https://assets.fis-ski.com/f/252177/x/325ce17d30/icr_01-07-25.pdf>
* FIS 규정 요약(게이트 = 폴 4개 + 0.75×0.50 m 패널 2장, GS 폭 4~8 m, 연속 터닝 폴 10 m 이상)
  <https://opensourcesports.io/rules/alpine-skiing-fis/playing-area-3-4-gates-and-course-setting>
  <https://pedia.games/en/games/alpine-skiing/rules/alpine-skiing-giant-slalom-fis>
  <https://www.crans-montana.com/en/worlds-2027/disciplines/giant-slalom>

## v2.1 에서 바뀐 것

**조작**
* 터치 드래그(아날로그 조향 `input.axis`) + 좌/우 절반 홀드 + 아래로 스와이프 브레이크.
* `steer` 댐핑 7 → **9.6**, `edge` 댐핑 4.2 → **9.0**, 최대 에지 58° → **64°**, 선회 상한 1.45 → 1.7 rad/s.
  답답하던 턴이 즉각적으로 붙으면서도 `ω = g·tan(edge)/v` 카빙 아치는 유지됩니다.
* 하단 터치 UI 정리: `BRAKE` / `CROUCH` 홀드 패드 + 드래그 안내만.

**게이트 코스** (v2.2 에서 FIS 규격으로 전면 교체됨)
* ~~좌우로 리드미컬하게 꺾이는 슈퍼G 세팅~~ → 롱/미디엄/숏 턴 + 딜레이드 게이트 세팅(v2.2).
* ~~발광 점선 가이드~~ → 스프레이 질감의 블루 다이 레이싱 라인(v2.2).
* ~~폴 하나짜리 힌지~~ → 깃발 세트(패널) 단위 힌지(v2.2).

**크라우칭**
* `rider.js` 의 턱 포즈를 실제 다운힐 에어로 자세로: 몸통을 지면과 **6.7°**(≈83° 숙임)까지 눕히고,
  엉덩이 0.98 → **0.46 m**, 어깨 1.35 → **0.52 m** 로 낮추며, 무릎을 깊게 접고 양팔을 가슴 앞으로 모아
  폴대를 몸통 옆·뒤로 일직선으로 눕힙니다(팔 길이 계산 버그도 함께 수정).
* 턱 시 항력 감소 + 가속 보너스, 추적 카메라 FOV 확대, 화면 속도선 오버레이로 속도감을 같이 올렸습니다.

**점프 제거 (RACE)**
* `Space` 입력은 RACE 에서 무시되고, 모바일 `AIR` 버튼은 `body.race` 에서 `display:none`.
  물리도 `input.allowJump === false` 로 한 번 더 막습니다.

**레퍼런스(carvemania.com) 반영**
* 카메라를 더 낮고 가깝게(4.15 m + 속도 보정, 높이 1.82 m), 세로 화면에서는 FOV 를 자동으로 넓혀 라이더가 프레임에 남습니다.
* HUD 재구성: 상단 중앙 대형 타이머 + 국기 바 + PB 스트립, 좌상단 코스 칩/일시정지, 우상단 **Course Setter** 목표 기록,
  좌하단 속도·게이트 카운터, 하단 중앙 조작 힌트.
* 메뉴를 `PICK YOUR FIRST RUN` 2장 카드(RACE/PARK, 인게임 아트)로 교체. 모드 전환 중 재구성 프레임에서 생기던 예외도 수정.

### 상점 (테스트 결제)

스킨 4종(Classic / Neon Cyber / Crimson Pro / Golden Legend)과 맵 3종(Larchwood / Glacier / Midnight)을
**테스트 결제**로 잠금 해제합니다. 실제 금액은 청구되지 않으며 보유 상태는 `localStorage`(`carve.store.v2`)에 저장됩니다.

게임 코드는 그대로 유지됩니다. 리더보드/고스트도 `src/services/leaderboard.js` 의 동일한 경계로 분리되어 있습니다.

* 추적 카메라의 **롤 기울기 + 속도 연동 FOV + 착지 셰이크 + 지형 클램프**.
* **Web Audio 절차적 사운드**(오디오 파일 없음): 속도 연동 바람, 카빙 스크레이프, 게이트 차임, 카운트다운, 착지, 구매음 + 음소거.

## 프로젝트 구조

```
index.html            ← vite build 산출물 (GitHub Pages 가 그대로 서빙)
assets/               ← 빌드된 JS 번들
app/                  ← 편집 가능한 소스 루트 (vite root)
  index.html
  src/
    main.js               부트스트랩 · 상태머신 · HUD 배선 · 테스트 훅
    core/noise.js         노이즈 · 감쇠 · 포맷 유틸
    scene/terrain.js      해석적 설면 높이 함수(물리·렌더 공용) + 메시
    scene/maps.js         3개 맵 데이터(팔레트·안개·파크 피처)
    scene/world.js        산맥·숲·B-net·아치·바위·레일·조명
    scene/sky.js          스카이 셰이더 + 환경맵
    scene/gates.js        FIS 게이트(폴4+패널2) · 블루 다이 라인 · 힌지 폴 · 통과 판정
    scene/rider.js        관절 스키어 모델 + IK/포즈
    scene/effects.js      스프레이 · 스파크 · 스키 자국
    scene/camera.js       체이스 카메라
    physics/skier.js      카빙 물리 · 점프 · 레일
    audio/audio.js        Web Audio 합성
    ui/hud.js shop.js touch.js
    services/store.js leaderboard.js
vite.config.js        base '/carve-ski-game/', build outDir '../'
```

### 빌드 / 배포

```bash
npm install
npm run dev      # http://127.0.0.1:5180/carve-ski-game/
npm run build    # 저장소 루트에 index.html + assets/ 생성 (Pages 가 즉시 서빙)
```

`vite.config.js` 는 `base: '/carve-ski-game/'`, `build.outDir: '../'` 로 설정되어 있어
**GitHub Pages 설정(Deploy from branch → main / root)을 건드리지 않고도** 빌드 결과가 바로 배포됩니다.

### 검증용 훅

`window.__carve` 는 자동화 검증용입니다: `ready`, `state()`, `start(mode)`, `advance(sec)`, `freeze(v)`,
`setInput()`, `autopilot(bool)`, `teleport(z, dx)`, `inspect()`, `render()`, `quality('low'|'high')`,
`gateDebug()` (28개 게이트의 색·폭·폴/패널 수·터닝/아웃사이드 폴 좌표·판정값).
